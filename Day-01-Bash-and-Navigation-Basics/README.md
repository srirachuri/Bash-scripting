## ⚡ Commands Used

### Print Current Working Directory
```
pwd
```

Displays the full path of the current directory.

### List Files and Directories
```
ls
```

Lists the files and folders in the current directory.

### Long Listing Format
```
ls -l
```

Displays detailed information including permissions, owner, size, and modification date.

### View Hidden Files
```
ls -a
```

Shows all files, including hidden files beginning with a dot (`.`).

### Create a Directory
```
mkdir bash_day1
```

Creates a new directory named **bash_day1**.

### Change Directory
```bash
cd bash_day1
```

Moves into the newly created directory.

### Return to Parent Directory
```
cd ..
```

Moves one level up in the directory structure.

### Return to Home Directory
```
cd ~
```

Navigates directly to the user's home directory.
