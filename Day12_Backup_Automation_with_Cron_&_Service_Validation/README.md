Day 12 – Backup Automation with Cron and Service Validation
Overview

This project automates file backups using Bash scripting and Cron scheduling. It also validates network connectivity and web service availability using Linux networking tools.

Objectives
Create automated backups using tar
Schedule backups using cron
Verify website availability using curl
Test network connectivity using nc
Generate backup logs for monitoring
Skills Practiced
Bash Scripting
Linux File Management
Cron Job Automation
Network Validation
Log Management
System Administration Basics
Files
backup.sh

Main backup automation script.

backup.log

Stores backup execution logs.

data/

Contains sample files used for backup testing.

backup_YYYY-MM-DD.tar.gz

Compressed backup archive generated by the script.

Script Workflow
Step 1: Create Sample Data
mkdir -p data
echo "Important file 1" > data/file1.txt
echo "Important file 2" > data/file2.txt
Step 2: Create Backup Archive
tar -czf backup_$(date +%F).tar.gz data
Step 3: Automate with Cron
crontab -e

Example:

0 2 * * * /home/user/bash_project/backup.sh >> /home/user/bash_project/backup.log 2>&1

Runs daily at 2:00 AM.

Step 4: Validate Connectivity

Check website headers:

curl -I https://google.com

Test TCP connectivity:

nc -zv google.com 80
